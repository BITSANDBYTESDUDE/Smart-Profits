Phase 1 Idea PitchSecure FinTech, Payments & Anti-Fraud

1. Problem statement and context

The P&L lives in Excel. So does the fraud.

Financial blindness

MENA merchants run shops from messy Arabic and English Excel, CSV, PDF and photos. Rent and salaries are missing. Phantom profit looks healthy.

Profit leakage

Weak SKUs and unplanned OpEx hide real net profit. A “good month” in the sales sheet can still be cash-negative for the store.

Account takeover

A SIM swap beats SMS OTP. The attacker then downloads P&L reports, changes prices, or steals the files that are the business.

Banks already buy network APIs. The SaaS that holds the merchant’s books usually does not. That is the Theme 4 gap.

2. Solution and Nokia CAMARA APIs

One platform. Two brains. Three network APIs.

Financial AI

Cleans messy Excel/CSV/PDF. Diagnoses health, leaks, inventory and a 30-day plan. Answers from the currently open file in Arabic or English.

Smart Guard AI Agent

On login, reset, upload, export and price change, the agent calls Nokia Network-as-Code and decides Allow / Step-up / Freeze.

Number VerificationSilent 4G/5G login check. Confirm the live network number. No extra SMS.
SIM SwapLogin, reset, price change. Recent swap → freeze. SMS OTP is untrusted.
Location VerificationFinancial upload and P&L export must match the usual store / branch area.

Testing uses Nokia Network-as-Code developer portal simulators, then maps one-to-one onto production CAMARA endpoints.
